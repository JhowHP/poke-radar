# 1. Objetivo

Este documento define a evolução planejada do PokéRadar.

O objetivo é transformar a plataforma inicialmente criada para monitoramento de promoções Pokémon TCG em uma solução completa de inteligência de mercado.

---

# 2. Visão Geral

Evolução:

```text
Monitor de preços

↓

Comparador de ofertas

↓

Sistema de oportunidades

↓

Inteligência de mercado

↓

Plataforma Pokémon TCG Brasil
```
