# Objetivo

Este documento apresenta o Modelo Entidade-Relacionamento (ER) do PokéRadar para a versão MVP.

O objetivo é representar visualmente as principais entidades do sistema e seus relacionamentos, servindo como base para a implementação do banco de dados.

---

# Relacionamentos

## Expansion → Product

Uma expansão possui diversos produtos.

Cada produto pertence a apenas uma expansão.

---

## Product → Offer

Um produto pode possuir diversas ofertas.

Cada oferta representa um anúncio específico em uma loja.

---

## Store → Offer

Uma loja pode possuir diversas ofertas.

Cada oferta pertence a apenas uma loja.

---

## Offer → PriceSnapshot

Uma oferta gera diversos snapshots ao longo do tempo.

Os snapshots nunca são alterados.

---

## Offer → Promotion

Uma oferta pode gerar diversas promoções detectadas pelo PIE.

---

## Offer → Opportunity

Cada oferta possui apenas uma oportunidade vigente.

Ela poderá ser recalculada sempre que novos dados forem capturados.

---

## Collector → CollectorJob

Cada coletor executa diversas coletas.

---

## CollectorJob → PriceSnapshot

Cada execução pode gerar diversos snapshots.

---

# Considerações

Este diagrama representa exclusivamente o núcleo da plataforma.

Novas entidades, como Usuário, Favoritos, Portfólio, Alertas e IA, serão adicionadas em versões futuras sem alterar significativamente o modelo central.
