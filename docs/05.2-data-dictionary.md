# Objetivo

Este documento descreve todas as entidades do banco de dados utilizadas no MVP do PokéRadar, incluindo seus principais atributos, responsabilidades e regras de negócio.

A modelagem física será implementada posteriormente utilizando PostgreSQL, SQLAlchemy e Alembic.

---

# Convenções

## Chaves Primárias

Todas as entidades utilizarão:

* UUID como chave primária (`id`).

---

## Auditoria

Sempre que aplicável:

* created_at
* updated_at

---

## Datas

Todas as datas serão armazenadas em UTC.

---

## Valores Monetários

Todos os valores monetários utilizarão tipo decimal (`NUMERIC`) para evitar problemas de precisão.

# Regras Gerais

* Toda entidade deve possuir chave primária UUID.
* Toda relação deverá utilizar chave estrangeira.
* Snapshots nunca serão atualizados.
* O histórico de preços será preservado permanentemente.
* Migrações serão realizadas exclusivamente via Alembic.
* Toda alteração estrutural deverá atualizar esta documentação.
